Section 02

Important Grid Properties

Learn the most important Grid properties and their Tailwind CSS equivalents.

display

grid

Enables Grid layout.

grid-template-columns

grid-cols-3

Controls the columns of the Grid.

grid-template-rows

grid-rows-2

Controls Grid rows.

gap

gap-4

Creates space between rows and columns.

grid-column

col-span-2

Makes an item span across two columns.

grid-row

row-span-2

Makes an item span across two rows.

grid-template-areas

grid-template-areas

Creates named areas for a page layout.

align-items

items-center

Aligns items vertically inside their grid area.

justify-items

justify-items-center

Aligns items horizontally inside their grid area.

CSS → Tailwind Cheat Sheet

CSS Property Tailwind Class Meaning
display: grid grid Enable Grid
grid-template-columns grid-cols-3 Create 3 columns
gap gap-4 Space between items
grid-column: span 2 col-span-2 Span 2 columns
grid-row: span 2 row-span-2 Span 2 rows
align-items: center items-center Vertical alignment
justify-items: center justify-items-center Horizontal alignment
